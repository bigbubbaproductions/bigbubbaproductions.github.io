# bigbubbaproductions.com (bare domain)

The bare domain `bigbubbaproductions.com` is served by GitHub Pages only so that it can host
[`app-ads.txt`](app-ads.txt), which AdMob and ad buyers read to confirm who may sell ads in Big Bubba Productions
LLC's apps. Every other page redirects to the main site at https://www.bigbubbaproductions.com (Google Sites).

The source of these files lives in the private Bubba Chop Grove repo (`store/web/`).
